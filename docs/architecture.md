## 4. 关键设计决策（ADR）

> ✍️ 每个关键选择按五段写：背景 → 选项 → 决定 → 理由 → 代价。
> 建议至少讨论下面这些点：

- [ ] 单例用哪种写法（手动 new / Meyers）
- [ ] 注册表用什么容器（map / unordered_map / vector）
- [ ] 节点由谁持有（裸指针 / unique_ptr / shared_ptr）
- [ ] 消息怎么传（按值 / const 引用 / 智能指针）
- [ ] 要不要引入多线程（作业的「异步」到底指什么）
- [ ] 时间戳怎么生成（localtime 线程安全吗）
- [ ] 异常在哪抛、在哪 catch
- [ ] 日志器怎么保证不抛异常
