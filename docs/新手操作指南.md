## 三、先理解三个地方

| 地方 | 是什么 | 在哪 |
| --- | --- | --- |
| 工作区 | 你正在编辑的代码 | `ros-sim\` 文件夹 |
| 本地仓库 | 你的存档记录 | `ros-sim\.git\`（隐藏文件夹） |
| 远程仓库 | 网上的备份 | GitHub 网站 |

**关键**：改了文件 ≠ 存档 ≠ 上传。这是三件独立的事，初学最容易懵在这里。

## 四、四个命令分别干什么

```powershell
git status              # ① 看：现在改了哪些文件
git add .               # ② 装：把改动放进"待提交"的篮子
git commit -m "说明"    # ③ 存档：给当前状态拍张照，写上说明
git push                # ④ 上传：把存档发到 GitHub
```

打个比方：

> 草稿纸（工作区）→ 装进文件袋（add）→ 装订成册贴标签（commit）→ 寄到图书馆（push）

### 每一步实际会看到什么

**① `git status`**

```
On branch main
Changes not staged for commit:
  modified:   CMakeLists.txt
Untracked files:
  include/ros/message.hpp
  src/message.cpp
```

红色 / untracked = 还没进篮子。

**② `git add .`** 之后再 `git status`：

```
Changes to be committed:
  modified:   CMakeLists.txt
  new file:   include/ros/message.hpp
  new file:   src/message.cpp
```

变成绿色 `Changes to be committed`，说明进篮子成功。

**③ `git commit -m "feat: 实现 Message 类"`**

```
[main 3f2a1b0] feat: 实现 Message 类
 3 files changed, 120 insertions(+)
```

方括号里那串 `3f2a1b0` 就是这次存档的编号。

**④ `git push`**

```
To https://github.com/PanShuYi0620/ros-sim.git
   61777e0..3f2a1b0  main -> main
```

看到 `main -> main` 就成功了。刷新 GitHub 页面能看到新文件。

## 五、完整走一遍（以写 Message 类为例）

1. CLion 打开项目
2. 新建 `include/ros/message.hpp` 和 `src/message.cpp`
3. 写代码，编译运行，确认没问题


## 六、提交信息怎么写

格式：`前缀: 一句话说明`

| 前缀 | 用途 | 例子 |
| --- | --- | --- |
| `feat` | 新功能 | `feat: 实现 Publisher 发布消息` |
| `fix` | 修 bug | `fix: 修复空节点名未拦截` |
| `docs` | 文档 | `docs: 添加需求文档` |
| `test` | 测试 | `test: 补充异常场景用例` |
| `chore` | 杂项 | `chore: 初始化项目骨架` |

> 老师看的就是这些记录（增量开发 10 分），所以**一次提交只做一件事**，写清楚。

## 七、常见问题

**Q：commit 和 push 有什么区别？**
commit 是存到**本地**，断网也能做，做多少次都行；push 是**传到网上**，需要联网和登录。可以先 commit 三次，再 push 一次。

**Q：只 push 不 commit 行不行？**
不行。push 传的是"提交"，没有提交就没东西可传。

**Q：commit 了但忘了 push，会丢吗？**
不会。本地有存档，只是 GitHub 上看不到，下次补 `git push` 就行。

**Q：一天要提交几次？**
每做完一个**能跑通**的小功能提交一次。不要攒到最后一次性提交几十个文件。

**Q：push 报错 `rejected` 怎么办？**
先 `git pull --rebase` 再 `git push`。个人仓库很少遇到。

**Q：push 时提示输入密码？**
GitHub 已经不接受密码了。等浏览器弹窗，点 **Authorize** 授权即可。

**Q：改错了想撤销？**
- 还没 add：`git restore 文件名`
- 已经 add 没 commit：`git restore --staged 文件名`
- 已经 commit 没 push：`git commit --amend -m "新说明"`

**Q：提示 `fatal: not a git repository`？**
当前目录不对，先 `cd` 到 `ros-sim` 文件夹。

## 八、命令速查表

| 我想…… | 命令 |
| --- | --- |
| 看改了哪些文件 | `git status` |
| 看具体改了什么 | `git diff` |
| 看提交历史 | `git log --oneline` |
| 暂存全部改动 | `git add .` |
| 提交 | `git commit -m "说明"` |
| 上传 | `git push` |
| 丢弃未提交的修改 | `git restore 文件名` |
| 取消暂存 | `git restore --staged 文件名` |
| 改最近一次提交说明 | `git commit --amend -m "新说明"` |

## 九、每次提交前的检查清单

- [ ] 代码能编译通过、能运行
- [ ] `git status` 里没有 `build/`、`.idea/` 这类不该提交的东西
- [ ] 提交信息写清楚了做了什么
- [ ] `git push` 之后刷新 GitHub，确认文件真的上去了
